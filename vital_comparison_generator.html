VITAL COMPARISON Generator v5.1

Aplikasi lokal HTML untuk generate spreadsheet VITAL_COMPARISON dari VITAL_DATASHEET, PDC SHEETS REDLINE per sequence, dan optional PDF OCALC report.

Catatan: PDC SHEETS REDLINE sekarang bisa di-upload sebagai beberapa PDF per sequence agar matching lebih akurat. Nama file sebaiknya berisi sequence. PDF OCALC bersifat optional; jika tidak di-upload, kolom OCALC/Riser/VGR/C-TRUSS/Note dikosongkan.

1. VITAL_DATASHEET Required

2. PDC SHEETS REDLINE Required

Upload PDF PDC per sequence. Nama file sebaiknya mengandung sequence, contoh: P121.pdf atau 121.pdf.

3. OCALC PDF Reports Optional

Upload semua/sebagian PDF OCALC report. Sequence akan dicocokkan dari nama file atau isi report.
