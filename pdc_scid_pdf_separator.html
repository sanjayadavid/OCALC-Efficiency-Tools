Upload satu PDF PDC Sheets gabungan. Tools ini akan membaca SCID pada tiap halaman, lalu membuat file PDF terpisah dengan nama hanya angka/huruf SCID-nya saja, contoh: 2080.pdf atau 2085A.pdf.

Catatan Deteksi

Regex default mencari format seperti Scid: 2080, SCID 2080A, atau Scid: 121316348. Nama file output hanya memakai nilai di belakang label SCID, misalnya 2080.pdf atau 2085A.pdf.

Kalau ada halaman yang gagal terbaca, hasilnya akan diberi nama UNKNOWN_PAGE_... dan bisa diedit manual di tabel sebelum download.
